# Security

This is an independent port of NVIDIA Warp to AMD GPUs on Windows. To report a security issue in the port itself (its HIP backend
and the other changes listed in NOTICE.md), email the address under Contact in the README instead of opening a public issue.

An issue that also occurs in NVIDIA Warp on NVIDIA GPUs belongs to NVIDIA. Report it as the security policy of
[NVIDIA Warp](https://github.com/NVIDIA/warp/security) describes.
